# 单事实检索失败诊断

## 结论

`cookie-01` 和 `cookie-02` 的主要失败点在检索链路，而不是回答模型。
BM25 对两道题都把包含完整答案的 Cookie 片段排在第一，但命令行评测入口
没有初始化 BM25，实际退化成向量检索加重排。回答模型因此没有足够证据，
选择拒答或返回空答案。

同时发现关键词索引缺少 `filename` 元数据。即使 BM25 找到正确片段，片段
独立进入融合结果时也无法被文档召回指标和引用系统正确归属。

## 复现配置

- 知识库：`RAG Evaluation`
- 知识库 ID：`2e09fbb2-db8a-4631-a915-18167bb7602b`
- 查询模式：standard（Auto 对两题的实际路由）
- `top_k`：5
- 向量候选数：10
- BM25 候选数：10
- Cross-encoder：启用

## 分阶段证据

### cookie-01

问题：

> Secure 和 HttpOnly Cookie 属性分别防范什么风险？

BM25 第一名是 `mdn-http-cookies.md` 的 chunk 12。该片段同时包含
`Secure`、`HttpOnly`、HTTPS 和中间人攻击信息，紧邻的 chunk 13 包含
JavaScript、`Document.cookie` 和 XSS 信息。

旧版最终上下文没有 chunk 12 或 13。五条结果主要是 HTTP 缓存 RFC、参考
链接和索引片段，回答为空或拒答。

修复后最终上下文：

1. `mdn-http-cookies.md` chunk 12
2. `mdn-http-cookies.md` chunk 13
3. `mdn-http-cookies.md` chunk 22
4. `mdn-http-cookies.md` chunk 21
5. `mdn-http-caching.md` chunk 50

回答层复验正确给出：

- Secure 仅通过 HTTPS 发送，降低中间人窃听风险；
- HttpOnly 禁止 JavaScript 访问，缓解 XSS 窃取风险。

### cookie-02

问题：

> Cookie 的 Max-Age 和 Expires 同时设置时哪个优先？

BM25 第一名是 `mdn-http-cookies.md` 的 chunk 5。该片段明确说明
`Max-Age` 比 `Expires` 更不易出错，并在两者同时设置时优先。

旧版最终上下文五条全部来自 `rfc9111-http-caching.pdf`，讨论的是 HTTP
缓存头而不是 Cookie 属性。回答模型据此明确表示知识库无法确认。

修复后 chunk 5 位于最终上下文第一名，且元数据正确记录为
`mdn-http-cookies.md`。回答层复验正确指出 `Max-Age` 优先，并解释其相对
时间语义避免了客户端和服务器时钟差异。

## 根因

### 评测入口没有初始化 BM25

`benchmark_runner.py` 直接导入产品回答路径，但不会执行 FastAPI lifespan。
旧评测入口也没有自行重建关键词索引，因此新进程中的 BM25 引擎为空，混合
检索静默退化成纯向量候选。Web 服务和评测 CLI 由此运行了不同的检索路径。

### 重排器可能误杀精确词法结果

旧实现让 Cross-encoder 结果直接覆盖融合排序。对于中文问题和英文技术文档
的混合语言场景，这会使单个重排器有机会删除独立检索器的最强精确匹配，
形成灾难性假阴性。最终结果应保留一条独立词法证据。

### 关键词索引元数据不完整

关键词索引重建只读取 `chunks` 表。文件名存储在 `documents` 表，因此
BM25 独立候选的 `filename` 为空。服务启动时的重建 SQL 也存在同一问题。

## 修复

- Cross-encoder 继续负责主要排序，但保留 BM25 第一名作为独立词法证据，
  其余位置由重排结果填充。
- 命令行评测在运行问题前从数据库重建目标知识库的 BM25 索引，确保与产品
  服务使用相同的混合检索路径。
- chunk 查询联结 documents 表，为关键词索引补齐文件名。
- 服务启动重建关键词索引时使用同样的联结查询。
- 增加连字符技术属性、中英文混合查询、BM25 精确事实排序和重排误杀保护
  的离线回归测试。

该修复不针对 Cookie、具体属性名或文件名添加生产代码特例，不新增模型
调用，也不扩大候选池。

## 模型因素判断

相同模型在获得修复后的上下文后，两道题均一次回答正确。因此本次失败不需要
通过更换回答模型解决。模型仍可能影响措辞和事实覆盖率波动，但不是这两个
稳定失败的首要根因。
